# x-post

Write like a **voice memo** typed out - a person posting from their phone, not a brand.

A post carries **one beat**. Name something **specific**. Leave a **rough edge**.

## Steps

### 1. Lock the angle

Before drafting, pin down:

1. What is this actually about (product, feeling, observation)?
2. Why would a stranger stop scrolling?
3. Single or thread?

If the user already gave a draft to humanize, extract the angle from that draft - do not invent a new pitch.

Completion: one plain sentence of the form "this post says X, and someone cares because Y."

### 2. Draft cold

Write 2-3 candidates at different energy levels (dry / playful / blunt). Prefer short.

Rules while drafting:

- **one beat** - one claim, one moment, or one ask. Threads = one beat per tweet.
- **specific** - a command, a file, a number, a concrete annoyance. Categories are dead on arrival.
- **voice memo** - contractions, fragments, lowercase-ok, starts mid-thought ok. Read it out loud in your head; if you would not say it, cut it.
- **rough edge** - keep one small human mark (a half-finished thought, a dry aside, mild slang, uneven line breaks). Smooth is the default failure mode.

Length: aim under 240 characters so it still breathes on X. Mark anything longer as a thread and split on beats.

Completion: every candidate states the angle from step 1, stays inside the length bound (or is an explicit thread), and survives a silent read-aloud without cringe.

### 3. Voice pass

Run each candidate through the checklist in [VOICE.md](VOICE.md). Rewrite anything that fails a line - do not just note it.

Completion: every candidate passes every line of the voice pass; the angle is unchanged.

### 4. Hand over

Return the candidates as ready-to-paste blocks. No essay about why they work. At most one short line naming the energy of each ("dry", "playful", "blunt").

If the user asked to humanize one draft, return the rewritten version plus one alternate - not a pile.

Completion: user can copy-paste a post without editing your scaffolding.
