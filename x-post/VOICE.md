# Voice pass

Apply every line. Rewrite on fail. This is the single source of truth for "sounds human."

## Shape

| Pass when | Fail when |
|---|---|
| Opens on the thing itself | Opens with a setup, throat-clear, or "So I built..." windup that delays the point |
| One beat lands and stops | Stacks benefits, feature lists, or a second pitch after the close |
| Line breaks follow breath | Symmetrical stanzas, bullet-shaped tweets, or slogan cadence |
| Ends on the thought or a quiet ask | Ends on a slogan, hashtag pile, or "link in bio" energy |

## Diction

| Reach for | Leave behind |
|---|---|
| Concrete nouns and verbs the user would type | Abstract praise: seamless, robust, powerful, elegant, next-level |
| Plain connectives: so, but, and, just | Essay connectives: moreover, furthermore, in today's world |
| One ordinary word | Paired adjectives and triad stacks ("fast, simple, and delightful") |

## Texture

| Pass when | Fail when |
|---|---|
| Reads like a slack message to a sharp friend | Reads like a launch blog intro or Product Hunt blurb |
| Rhythm is uneven - short then long, or a fragment | Even, polished cadence with every sentence the same length |
| At least one rough edge remains | Everything is symmetrically clean, capitalized, and "ready for brand" |
| Emoji: zero, or one if the user already talks that way | Emoji as decoration or section markers |
| Hashtags: none, unless the user asked | Hashtag trails |

## Hard limits

These are the few bans that earn their place - each paired with the move to make instead:

- Prefer a plain hyphen `-` or a period over an em dash. Break into two sentences if needed.
- Prefer "I" / "you" / no pronoun over "one" / "users" / "developers" as a faceless mass.
- Prefer showing the install line or command over narrating how easy it is.

## Quick self-test

Read the draft once as if a cynical friend sent it in a group chat.

- Would you believe a human typed this in under a minute?
- Is there a single sentence you would actually say out loud?

If either answer is no, rewrite from the angle - do not polish the same sentences.
